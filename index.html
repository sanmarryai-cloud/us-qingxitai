    2.0 执行规则（控制回撤）2.0 Execution rules (drawdown control) · v2.1

    先找强股 → 等确认 → 小风险进场 → 1.5–2R 先兑现一部分 → 强就让利润跑 → 弱就价格止损或时间止损。Find strength → wait for confirmation → small-risk entry → bank part at 1.5–2R → let winners run → exit on price or time stop if weak.

    2–5 个交易日是「证明自己」的窗口，不是强制到期日：提前走强可继续持有；三四天不动则清理。2–5 sessions is a prove-it window, not a hard expiry: keep if already strong; clear if still dead after 3–4 days.

    仅作分析参考框架，非投资建议；不下单。止损在剧烈波动下可能滑点（杠杆/高波动风险更大）。Reference framework only — not advice; no orders placed. Stops can slip in fast markets (leverage/high-vol amplify risk).

    六条硬规则Six hard rules

    • 1. 先定止损，再定仓位1. Define stop first, then size
      例如买 $100、技术止损 $96 → 每股风险 $4（1R=$4）。若单笔最多亏账户 0.5%，用风险反推股数，而不是先买再想止损。保证金/杠杆时更严格。e.g. buy $100, technical stop $96 → $4 risk/share (1R=$4). Cap loss at e.g. 0.5% of equity and back into shares — never size first then invent a stop. Stricter with margin/leverage.
    • 2. 用 R 倍数管盈利，不用固定涨跌幅2. Manage profits in R, not fixed %
      涨到 $106 = +1.5R；涨到 $108 = +2R。爆发股到 1.5–2R 可先卖 1/3～1/2，剩余跟 5日线/10日线或前一日低点。比「一律涨 10% 就卖」更合理。+$6 on a $4 stop = +1.5R; +$8 = +2R. On bursts, bank 1/3–1/2 at 1.5–2R; trail the rest with 5/10-day MA or prior-day low. Better than a flat +10% sell rule.
    • 3. 时间止损（证明窗口）3. Time stop (prove-it window)
      A 爆发：第1天不涨、第2天仍弱、第3天仍无量价配合 → 即使未触及价格止损也开始退出。买的理由是「马上爆发」；没爆发，逻辑已弱。注意：若第3天已大涨且结构漂亮，不必因「到5天」机械卖掉。A-burst: day1 flat, day2 weak, day3 still no volume/price follow-through → start exiting even if price stop untouched. Thesis was immediate thrust. Exception: if already strongly up with clean structure by day3, do not force-sell just because day5 arrived.
    • 4. 突破股不提前猜4. Do not front-run breakouts
      A 近突破：关键价位突破 → 成交量确认 → 次日不迅速跌回突破位下。宁愿贵 2% 买确认，也不为便宜 2% 提前赌。A-near: break level → volume confirm → next day does not quickly fail back below. Prefer paying ~2% for confirmation over guessing early to save 2%.
    • 5. 龙头可比爆发股拿更久5. Leaders may be held longer than bursts
      B 类趋势未坏不必涨 8–10% 就机械清仓。可用：跌破 10 日线减仓；跌破 20 日线/关键平台清掉。B 与 A 的卖法必须分开。B-leaders: do not mechanically dump at +8–10% if trend intact. Trim under 10-day MA; exit under 20-day MA / key shelf. B exits ≠ A exits.
    • 6. 事件股仓位最严6. Event names: smallest size
      财报/FDA/大单/合作/政策等可能隔夜跳空，止损单触发后成交价可能远离预期。C 类仓位应最小。Earnings/FDA/contracts/etc. can gap overnight; stop fills can slip far from the trigger. Keep C-event size smallest.

    分镜头卖法Lens exit bias

    • A_momentum_burst — 速度交易：1.5–2R 先兑现部分；弱则价格/时间止损；强则剩余跟短均线。Speed trade: partial at 1.5–2R; weak → price/time stop; strong → trail remainder on short MAs.
    • A_near_breakout — 等确认再进；失败跌回突破位下则快速离场。Enter only after confirmation; fail back under breakout → exit fast.
    • B_rs_leader — 趋势持有：10日减仓 / 20日或平台破坏清仓；不用固定%硬卖。Trend hold: trim under 10DMA / clear under 20DMA or shelf break; no fixed-% dump.
    • C_rvol_event — 催化驱动：最小仓；隔夜风险高；逻辑失效或跳空不利立即收缩。Catalyst-driven: smallest size; overnight gap risk; shrink fast if thesis fails.
    • D_oversold_bounce_watch — 仅观察，不是单独买点。Watch only — not a standalone entry.
    • F_volume_price_lift — 温和放量抬升：确认量价仍同步；若放量衰竭或跌回启动平台则时间/价格止损。仓位小于 A 爆发。Mild vol+price lift: keep only while volume still supports; exit if volume fades or price loses launch shelf. Size smaller than A-burst.
